# ANGELA'S NETTOYAGE

Website for professional home, office, and accommodation cleaning services in Porto and surrounding areas.

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Open the local URL printed by Next.js.

## Production build

```bash
pnpm build
pnpm start
```

The quote form prepares a WhatsApp message; this website does not store or submit customer details to a server.
